# Verificar tu correo electrónico

Después de crear tu cuenta, REDMIS te envía un código de verificación de 6 dígitos al correo electrónico que registraste. Necesitas confirmar este código antes de poder iniciar sesión.

1. Al terminar el registro, la plataforma te lleva automáticamente a la pantalla **Verificar Cuenta**.
2. Revisa tu bandeja de entrada (y la carpeta de spam, si no lo encuentras) y localiza el correo con el código de verificación.
3. Ingresa el código de 6 dígitos en el campo correspondiente.
4. Presiona **Verificar**. Si el código es correcto, verás un mensaje de confirmación y la plataforma te redirigirá a la pantalla de inicio de sesión.

## ¿No recibiste el código o ya expiró?

En la misma pantalla de verificación encontrarás la opción **Reenviar código**, que solicita un nuevo código al correo con el que te registraste.

## ¿Ingresaste un código incorrecto?

La plataforma te mostrará un mensaje de error y podrás intentarlo nuevamente sin perder tus datos de registro.

:::tip
No cierres ni recargues la pantalla de verificación antes de completar el proceso: el correo se identifica mediante un parámetro en la URL de esta página.
:::

## Siguiente paso

Una vez verificada tu cuenta, continúa con [Iniciar sesión](./iniciar-sesion).
