# Iniciar sesión

1. Ingresa tu correo electrónico y contraseña en la pantalla de inicio de sesión.
2. Presiona el ícono del ojo si deseas mostrar u ocultar tu contraseña mientras la escribes.
3. Al iniciar sesión correctamente, la plataforma te llevará a tu panel según tu rol:
   - **Usuario general**: acceso a perfil, membresías y solicitudes.
   - **Administrador**: acceso adicional al panel de administración.

:::info
Tu sesión se mantiene activa mediante un token que se guarda en tu navegador. Si cierras sesión desde el menú lateral, deberás iniciar sesión nuevamente para volver a acceder.
:::

## ¿Problemas para ingresar?

Revisa que tu correo y contraseña sean correctos. Si el problema persiste, contacta al equipo administrador de REDMIS.
