# Crear una cuenta

Para usar REDMIS necesitas registrarte con tus datos personales y académicos.

1. Entra a la página de inicio de sesión y selecciona la opción para **registrarte**.
2. Completa el formulario de registro con tu información personal (nombre, apellidos, género, correo y contraseña).
3. Selecciona tu país, estado y universidad de las listas desplegables.
4. Confirma tu contraseña y envía el formulario.
5. La plataforma te redirige automáticamente a la pantalla de **verificación de correo**, donde debes ingresar el código que se te envió (ver [Verificar tu correo electrónico](./verificar-correo)) para poder iniciar sesión.

## Requisitos del formulario

Antes de enviar la solicitud de registro, la plataforma valida lo siguiente:

- **Nombre y apellidos**: solo letras y espacios (no se permiten números ni símbolos).
- **Correo electrónico**: debe tener un formato válido.
- **Contraseña**: al menos 8 caracteres, con una letra mayúscula, una minúscula y un número.
- **Confirmar contraseña**: el campo de confirmación te indica en tiempo real si coincide con la contraseña ingresada.
- **Género, país, estado y universidad**: son campos obligatorios.

Si alguno de estos requisitos no se cumple, la plataforma te lo indicará y no podrás continuar hasta corregirlo.

:::tip
Los campos de país, estado y universidad están relacionados: al elegir un país se filtran automáticamente los estados disponibles de ese país.
:::

## Siguiente paso

Una vez creada tu cuenta, continúa con [Verificar tu correo electrónico](./verificar-correo) y después con [Iniciar sesión](./iniciar-sesion).
