# Crear una cuenta

Para usar REDMIS necesitas registrarte con tus datos personales y académicos.

1. Entra a la página de inicio de sesión y selecciona la opción para **registrarte**.
2. Completa el formulario de registro con tu información personal.
3. Selecciona tu país, estado y universidad de las listas desplegables.
4. Confirma tu contraseña y envía el formulario.
5. Verifica tu correo electrónico para activar la cuenta.

:::tip
Los campos de país, estado y universidad están relacionados: al elegir un país se filtran automáticamente los estados y universidades disponibles.
:::

## Siguiente paso

Una vez creada tu cuenta, continúa con [Iniciar sesión](./iniciar-sesion).
