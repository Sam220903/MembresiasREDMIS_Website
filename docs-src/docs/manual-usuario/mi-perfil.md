# Mi perfil

Desde la sección de perfil puedes revisar y actualizar tu información personal, tu línea de investigación y tu CV.

## Editar tu información

1. Abre la sección **Perfil** desde el menú lateral.
2. Presiona **Editar** para habilitar los campos.
3. Actualiza los campos que necesites: nombre, apellidos, género, correo, contraseña, universidad, país, estado y línea de investigación.
4. Los selectores de país, estado y universidad se actualizan de forma dependiente: al cambiar el país se recargan las opciones de estado disponibles para ese país.
5. Presiona el botón de aceptar (✓) para guardar los cambios, o el de cancelar (✗) para descartarlos.

:::tip
Mantén tu perfil actualizado, ya que esta información se utiliza al generar tus solicitudes de membresía y constancias.
:::

:::info
Si no deseas cambiar tu contraseña, deja el campo tal cual (se muestra oculto como `********`); solo se actualizará si escribes una nueva.
:::

## Línea de investigación

El campo **Línea de investigación** cuenta con autocompletado:

- Al escribir, la plataforma te sugiere líneas de investigación ya existentes que coincidan con lo que escribiste.
- Si seleccionas una sugerencia, tu perfil quedará asociado a esa línea existente.
- Si escribes un nombre que no existe en el catálogo, la plataforma te avisa que se creará una nueva línea de investigación con ese nombre al guardar tus cambios.
- Si dejas el campo vacío, se elimina la línea de investigación asociada a tu perfil.

## Tu CV

En la sección de perfil también puedes gestionar tu currículum (CV):

1. Al entrar en modo edición, aparece un campo para seleccionar un archivo.
2. Si ya tienes un CV registrado, se muestra una vista previa del PDF directamente en la página.
3. Al elegir un nuevo archivo, se muestra de inmediato una vista previa local del documento seleccionado (aún no se ha subido).
4. El nuevo CV solo se sube al servidor cuando guardas los cambios de tu perfil; si no seleccionas ningún archivo nuevo, se conserva el CV que ya tenías.

:::info
El CV debe estar en formato **PDF**. Este es el mismo documento que se adjunta al [solicitar una membresía](./solicitud-membresia/como-solicitar) y el que revisan los administradores.
:::
