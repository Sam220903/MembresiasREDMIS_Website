# Mi perfil

Desde la sección de perfil puedes revisar y actualizar tu información personal.

## Editar tu información

1. Abre la sección **Perfil** desde el menú lateral.
2. Actualiza los campos que necesites (país, estado, universidad, datos de contacto, entre otros).
3. Los selectores de país, estado y universidad se actualizan de forma dependiente: al cambiar el país se recargan las opciones de estado y universidad.
4. Guarda los cambios para que se reflejen en tu cuenta.

:::tip
Mantén tu perfil actualizado, ya que esta información se utiliza al generar tus solicitudes de membresía y constancias.
:::
