# Consultar mis membresías

En la sección **Membresías** puedes ver el listado de todas tus membresías, junto con su estado actual.

- Membresías activas.
- Membresías pendientes de aprobación.
- Membresías rechazadas, con el motivo indicado por el administrador (si aplica).
