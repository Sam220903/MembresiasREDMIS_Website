# Descargar constancia en PDF

1. Ve a la sección **Membresías**.
2. Ubica la membresía activa de la cual deseas obtener tu constancia.
3. Presiona el botón de descarga para generar el PDF.
4. El documento se genera automáticamente en tu navegador y se descarga a tu equipo.

:::info
La constancia se genera de forma local en tu navegador, por lo que no depende de un servicio externo.
:::
