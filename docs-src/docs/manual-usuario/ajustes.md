# Ajustes

Desde la sección **Ajustes** del menú lateral puedes personalizar tu experiencia en REDMIS. Esta sección está disponible tanto para usuarios generales como para administradores.

## Idioma

Elige entre **español** e **inglés**. La preferencia se guarda en tu navegador y se aplica de inmediato a toda la interfaz.

## Tema

Elige el tema visual de la plataforma entre tres opciones:

- **Sistema**: sigue automáticamente la preferencia de tu sistema operativo o navegador (claro u oscuro).
- **Claro**.
- **Oscuro**.

La preferencia de tema también se guarda en tu navegador, por lo que se mantiene entre sesiones en el mismo dispositivo.

:::tip
Si usas REDMIS desde distintos dispositivos, deberás configurar el idioma y el tema por separado en cada uno, ya que estas preferencias no se sincronizan con tu cuenta.
:::
