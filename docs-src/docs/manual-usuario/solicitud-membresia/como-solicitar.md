# Cómo solicitar una membresía

1. Ve a la sección **Solicitud de membresía** desde el menú lateral.
2. Elige el tipo de membresía al que deseas aplicar.
3. Completa la información solicitada en el formulario.
4. Adjunta tu CV en formato PDF (ver [Adjuntar CV](#adjuntar-cv)).
5. Envía la solicitud.

## Adjuntar CV

- El archivo debe estar en formato **PDF**.
- El sistema convierte el archivo automáticamente para enviarlo junto con tu solicitud.
- Verifica que el documento cargue correctamente antes de enviar el formulario.

Una vez enviada, tu solicitud quedará en estado **pendiente** hasta que un administrador la revise.
