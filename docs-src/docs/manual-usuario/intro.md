# Bienvenido al Manual de Usuario de REDMIS

REDMIS es la plataforma de gestión de membresías donde puedes registrarte, administrar tu perfil, solicitar tu membresía y consultar el estado de tus solicitudes.

Este manual está dirigido a **usuarios generales** de la plataforma. Si buscas información técnica sobre la arquitectura, la API o los módulos del proyecto, visita la sección [Desarrolladores](/desarrolladores/arquitectura).

## ¿Qué puedes hacer en esta guía?

- Crear tu cuenta e iniciar sesión.
- Editar tu información de perfil.
- Solicitar una membresía y dar seguimiento a tu solicitud.
- Consultar y descargar la constancia de tus membresías activas.
- Cambiar el idioma de la plataforma.

Usa el menú lateral para navegar entre las secciones.
