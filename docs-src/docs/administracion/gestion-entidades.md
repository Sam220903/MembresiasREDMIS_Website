# Gestión de entidades

Administra los catálogos utilizados en los formularios de registro y perfil:

- **Países**
- **Estados**
- **Universidades**

Estos catálogos alimentan los selectores dependientes que ven los usuarios al registrarse o editar su perfil.

## Cómo funciona la pantalla

- Las tres listas (países, estados y universidades) se muestran en la misma pantalla, cada una con su propio buscador y contador de resultados.
- Al seleccionar un **país** en la lista de países, las listas de **estados** y **universidades** se filtran para mostrar solo las entidades relacionadas con ese país.
- Cada elemento de las listas cuenta con botones para **editar** o **eliminar**; al eliminar, se solicita confirmación antes de completar la acción.
- Para agregar un país, estado o universidad nuevo, usa el botón de agregar correspondiente, que abre un formulario emergente. El mismo formulario se reutiliza para editar un elemento existente.

:::caution
Elimina países, estados o universidades con cuidado: si ya están en uso por algún miembro registrado, esto puede afectar la información mostrada en sus perfiles.
:::
