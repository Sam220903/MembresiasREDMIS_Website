# Tipos de membresía

En esta sección puedes dar de alta o eliminar los tipos de membresía disponibles para los usuarios al momento de solicitar su membresía.

- La lista muestra el nombre y el tipo de cada membresía registrada, con un buscador y un contador de resultados.
- Para agregar una nueva membresía, presiona el botón de agregar e ingresa su **nombre** y su **tipo** en el formulario emergente; ambos campos son obligatorios.
- Para eliminar una membresía existente, usa el botón de eliminar junto a ella; se solicita confirmación antes de completar la eliminación.

:::note
Actualmente no es posible editar una membresía ya creada: si necesitas cambiar su nombre o tipo, deberás eliminarla y crear una nueva.
:::
