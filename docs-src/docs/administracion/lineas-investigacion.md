# Líneas de investigación

Desde esta sección se administran las líneas de investigación disponibles en la plataforma, utilizadas para clasificar a los miembros según su área de interés.

- La lista muestra todas las líneas de investigación registradas, con un buscador y un contador de resultados.
- Para agregar una nueva línea, usa el botón de agregar, escribe el nombre en el formulario emergente y confirma.
- Para eliminar una línea existente, usa el botón de eliminar junto a ella; se solicita confirmación antes de completar la eliminación.

:::info
Los usuarios también pueden crear una nueva línea de investigación de forma indirecta, escribiendo un nombre que no exista todavía en el campo **Línea de investigación** de su perfil.
:::
