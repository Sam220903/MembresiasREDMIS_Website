# Panel de administración

Los usuarios con rol de **administrador** tienen acceso a un menú adicional con las siguientes herramientas:

- Gestión de solicitudes de membresía.
- Gestión de miembros y roles.
- Tipos de membresía.
- Gestión de entidades (países, estados, universidades).
- Líneas de investigación.
- Estadísticas.

Accede a estas herramientas desde la sección **Administración** del menú lateral.
