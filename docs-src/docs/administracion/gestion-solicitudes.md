# Gestión de solicitudes

1. Entra a la sección **Solicitudes** para ver el listado de solicitudes de membresía pendientes.
2. Selecciona una solicitud para ver su detalle: datos del solicitante, membresía solicitada, país, estado, universidad, línea de investigación, comentarios del solicitante y el CV adjuntado (visualizable en línea y descargable).
3. Para **aprobar** la solicitud, presiona el botón correspondiente; puedes añadir un comentario opcional antes de confirmar.
4. Para **rechazar** la solicitud, presiona el botón correspondiente; en este caso es **obligatorio** escribir el motivo del rechazo.
5. En ambos casos, el usuario solicitante recibe una notificación por correo electrónico informándole el resultado de su solicitud.
6. El usuario podrá ver el resultado desde su propia sección de membresías.
