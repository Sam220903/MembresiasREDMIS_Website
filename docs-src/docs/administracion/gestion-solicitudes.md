# Gestión de solicitudes

1. Entra a la sección **Solicitudes** para ver el listado de solicitudes de membresía pendientes.
2. Selecciona una solicitud para ver su detalle, incluyendo el CV adjuntado por el usuario.
3. Aprueba o rechaza la solicitud según corresponda.
4. El usuario podrá ver el resultado desde su propia sección de membresías.
