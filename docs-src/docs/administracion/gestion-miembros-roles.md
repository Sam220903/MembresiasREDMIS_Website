# Gestión de miembros y roles

Desde esta sección puedes administrar el rol de cada miembro registrado en la plataforma.

- **Administrador**: acceso completo a las herramientas de administración.
- **Usuario general**: acceso a las funciones de perfil, membresías y solicitudes.

Para cambiar el rol de un miembro, localízalo en el listado y actualiza su rol asignado.
